## Integrity chain

Each run metadata file records the configuration hash, dataset-manifest hash, dependency versions, package hashes, runner hash, and the hashes of the project-owned growth kernels. For new runs, the runner verifies every manifest-declared file before execution. The schema-v2 analyzer reconstructs the complete expected grid from the configuration and dataset manifest, then rejects missing conditions, missing pair members, duplicates, non-success records, unit mismatches, and mismatched clean or corrupted image hashes.

The held-out run is additionally anchored by `docs/test_split_freeze.json`, `docs/PREREGISTRATION.md`, and `docs/heldout_acceptance.json`. Paths in the freeze ledger are the source coordinates recorded at freeze time, not a claim that later release files at those active paths remain byte-identical. Exact test-run snapshots of the runner, analyzer, summarizer, experiment schema, and CLI are preserved under `docs/frozen_sources/`. Source changes made after an archived run are enumerated in `docs/ARCHIVED_RUN_PROVENANCE.md`.

The archived v0.1.0 metadata field `per_file_hashes_verified` predates the eager full-manifest pass introduced in v0.1.1. In those archived runs, each consumed image and annotation was checked against its manifest row before decoding; the field must not be read as evidence that unused files from other splits were pre-scanned. The manifest itself still carries byte sizes and SHA-256 values for all 1,000 files.

## Re-execution

Archived configurations point to immutable published outputs. For a fresh execution, copy a configuration and give the copy a new output path:

```powershell
Copy-Item configs\bsds500_multicorruption_v2_smoke_2x96_r2.json configs\local_smoke.json
# Edit configs\local_smoke.json and set output to experiments/runs/local_smoke.jsonl.
monogrowlab run --config configs\local_smoke.json
```

The runner is resumable: existing successful `run_key` records are skipped only after immutable metadata are revalidated. Directly running an archived configuration against its archived output therefore acts as a provenance check and is expected to fail closed if the installed package, dependencies, or platform differ from the recorded execution environment.

Rebuild derived artifacts with `monogrowlab analyze`, `monogrowlab summarize`, `monogrowlab report`, and `monogrowlab plot`, as shown in the root README.

The archived analysis directories omit `report.md` because that narrative view is regenerated by `monogrowlab analyze`; their CSV tables, analysis metadata, summaries, and standalone HTML reports are retained.

## Statistical unit

Inference is performed at image level. Confidence intervals use paired bootstrap resampling of images. Sign-flip permutation tests are exact for at most 18 images and Monte Carlo above that threshold. Holm correction is applied within each corruption family over the variants supplied as that analysis family's primary variants.
