# Version 0.1.2

- Add per-extremum-type cardinality matching with three deterministic draws, synchronized label/coordinate/statistics reindexing and a common matched-clean reference.
- Add seed-count, overlap, nearest-neighbour, spatial-support and coverage diagnostics.
- Add finite single-factor seed-sigma and CLERG growth-tolerance evaluation, retaining empty detector states and unavailable references explicitly.
- Add portable image-level analysis and archived supplementary evidence, with full-grid verification and NA propagation.
- Preserve existing numerical growth kernels, default configurations, metrics, CLI and browser workflow, and archived baseline/strict/held-out results.
- Report version 0.1.2 in the local web workbench and document starting it from the installed virtual environment.

Version 0.1.1 remains available as the previous public release.
