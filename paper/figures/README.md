# Figures

`fig1_architecture_v04.py` generates the architecture diagram. `publication_figures_v04.py` reads the archived inference CSV files under `reports/generated/` and generates Figures 3–6. Figure 2 is a screenshot of the completed local web workbench.

The PDF and SVG files are vector deliverables; PNG copies are included for convenient preview. Numerical values are read from CSV inputs rather than embedded in the plotting code.
